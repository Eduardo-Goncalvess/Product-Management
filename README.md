Download or clone this repository to your computer.
Open MySQL Workbench.
Connect to your local MySQL Server.
Open the file SQL TRABALHO.sql from the repository.
Execute the entire SQL script using the Execute button.
Wait for the script to finish creating the database tables and inserting the data.
Refresh the SCHEMAS panel in MySQL Workbench.
Select the created database and check its tables.
Run the available SQL queries from the script to test and explore the database.
